          BCA 1st Year Lab Viva & Debugging Guide
        

        
Essential distinctions every BCA student is examined on in practical exams


        

          
1. What is the difference between Syntax, Runtime, and Logical Errors?

          

            • Syntax Error: Violates grammar rules of the language (e.g. missing colon in Python, missing semicolon in C). Caught by compiler/parser before execution starts.

            • Runtime Error: Occurs while the program is executing (e.g. dividing by zero, TypeError when concatenating string to int, segmentation fault). Causes sudden crash.

            • Logical Error: The program compiles and runs smoothly without crashing, but calculates wrong outputs (e.g. uninitialized variable holding garbage memory, wrong loop condition). These are the most dangerous bugs in software!
          

        


        

          
2. Why does C give unpredictable huge numbers when variables aren't initialized?

          

            Unlike Python which automatically manages and zeros object allocations, C allocates raw memory cells directly on the stack. When you declare int sum; without = 0, the memory cell contains whatever random residual electrical bits were left over by previous programs (known as a garbage value).
          

        


        

          
3. Why doesn't Python allow "I am " + age + " years old"?

          

            Python is strongly typed. It deliberately avoids implicit type coercion. When Python sees +, it cannot guess if you intend to do mathematical addition or text concatenation. You must explicitly convert using str(age) or use modern formatted f-strings f"I am {age} years old.".
          

        


        

          
4. Why does scanf("%d", x) cause a Segmentation Fault in C?

          

            The scanf function requires the memory address where the input should be stored. Omitting the ampersand (&) passes the value of x rather than its memory location, prompting C to attempt writing to invalid protected operating system memory.
